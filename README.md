# Web Studio Mobile

Éditeur de code et visualiseur universel optimisé pour mobile (Material You / Google Pixel).

## Fonctionnalités
- Édition HTML, CSS, JavaScript, JSON, Python, C++
- Visualiseur et prévisualisation en temps réel (iframe sandboxée)
- Télémétrie en direct (nombre de caractères, sélection de lignes)
- Sauvegarde locale (LocalStorage / File System Access API)
- Coloration syntaxique & barre de numérotation tactile
